# Chapter 2 — Discovery

How a client or node finds the right peer for a given hash. Clients select nodes from the on-chain registry via probes; nodes use the DHT on cache-miss pulls; proxy warming bootstraps the first regional copy when discovery finds only distant holders. Discovery itself is unpaid — only the delivery that follows is metered.
