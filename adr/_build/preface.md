# About this PDF

This is the **reading-order build** of the deCDN protocol specification — every numbered ADR plus appendix, ordered by chapter (Foundations → Discovery → Payments → Tokenomics → Verification → Governance → Operations → Supporting → Appendices) rather than by ADR number.

**Sections omitted from this PDF:** *Deferred & Open* (deferred work / open questions) is stripped from this reading-order build so the document reads as a single canonical design; it is retained verbatim in the source `.md` files and the numeric `adrs.pdf` build. *Cross-ADR Impact* sections are retained — they carry substantive cross-cutting design content. Rejected pre-launch alternatives are not part of any ADR; they are archived in `adr/_history/alternatives-pre-launch.md`, which neither PDF includes.

The numeric per-ADR index in [Architecture Overview § Architectural Decisions](#architectural-decisions) stays as the canonical reference for citing a specific ADR.
