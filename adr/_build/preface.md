# About this PDF

This is the **reading-order build** of the deCDN protocol specification — every numbered ADR plus appendix, ordered by chapter (Foundations → Discovery → Payments → Tokenomics → Verification → Governance → Operations → Supporting → Appendices) rather than by ADR number.

**Sections omitted from this PDF:** *Deferred & Open* (deferred work / open questions), *Alternatives Considered* / *Considered Alternatives*, and *"Why not …"* subsections are stripped at build time so the document reads as a single canonical design rather than a debate transcript. *Cross-ADR Impact* sections are retained — they carry substantive cross-cutting design content. The omitted sections remain in the source `.md` files in `adr/` and in the numeric `adrs.pdf` build for readers who want the full decision-record context.

The numeric per-ADR index in [Architecture Overview § Architectural Decisions](#architectural-decisions) stays as the canonical reference for citing a specific ADR.
